# C4 Model Diagrams - UniHub Workshop

Tài liệu này bao gồm sơ đồ kiến trúc hệ thống UniHub Workshop thiết kế theo chuẩn C4 Model, thể hiện rõ hệ sinh thái của phần mềm từ góc nhìn tương tác cho đến kiến trúc các Container kỹ thuật đang chạy thực tế hiện tại.

## Level 1: System Context Diagram

Mô tả tổng quan sự tương tác giữa các nhóm người dùng (Actors) với Hệ thống UniHub Workshop và các Hệ thống bên ngoài có liên kết.

```mermaid
C4Context
    title C4 Level 1 - System Context (UniHub Workshop)

    Person(student, "Sinh viên", "Xem lịch, đăng ký tham gia workshop, nhận QR Code truy cập.")
    Person(admin, "Ban tổ chức", "Tạo, quản trị chuyên mục workshop, tải và import định kỳ tệp CSV từ hệ thống cũ.")
    Person(staff, "Nhân sự Check-in", "Kiểm soát ra vào tại cửa qua Mobile App, hỗ trợ quét QR offline khi không có mạng.")

    System(unihub, "UniHub Workshop System", "Hệ thống lõi quản lý hoạt động workshop, xử lý thanh toán, phân phát vé và quy trình check-in đồng bộ.")

    System_Ext(legacy, "Legacy System (SIS)", "Hệ thống quản lý trường học cũ, chứa dữ liệu chuẩn của sinh viên (Xuất CSV hàng ngày).")
    System_Ext(payos, "PayOS Gateway", "Hệ thống bên thứ 3 xử lý giao dịch thanh toán cho các workshop có thu phí.")
    System_Ext(aws, "AWS Services", "Cung cấp S3 (Lưu trữ ảnh sơ đồ, file CSV) và Serverless Lambda (Resize/Optimize ảnh).")
    System_Ext(cloudflare, "Cloudflare CDN", "Proxy server phân phối và lưu cache hình ảnh xử lý tốc độ cao tới frontend.")

    Rel(student, unihub, "Xem lịch & đăng ký", "HTTPS")
    Rel(admin, unihub, "Thiết lập cấu hình / Quản trị", "HTTPS")
    Rel(staff, unihub, "Quét vé / Sync dữ liệu check-in", "HTTPS")

    Rel(admin, legacy, "Trích xuất CSV ban đêm", "Thủ công / System Cron")
    Rel(unihub, payos, "Giao dịch thanh toán / Webhooks", "REST API")
    Rel(unihub, aws, "Get presigned URL, Get Object Streams", "AWS SDK")
    Rel(unihub, cloudflare, "Định tuyến client lấy ảnh", "HTTPS")
    Rel(cloudflare, aws, "Lấy ảnh nguồn/đã qua xử lý", "HTTPS")
```

## Level 2: Container Diagram

Chi tiết kiến trúc bên trong lớp `UniHub Workshop System`. Thể hiện các Container kỹ thuật chịu trách nhiệm vận hành theo đúng source code thực tế.

```mermaid
C4Container
    title C4 Level 2 - Container Diagram (UniHub Workshop)

    Person(student, "Sinh viên", "Đăng ký workshop")
    Person(admin, "Ban tổ chức", "Quản lý / Sync File")
    Person(staff, "Nhân sự Check-in", "Quét QR")

    System_Ext(payos, "PayOS Gateway", "Thanh toán (Circuit Breaker)")
    System_Ext(aws, "AWS S3 / Lambda", "Lưu trữ / Image Resize")

    Container_Boundary(unihub, "UniHub Workshop System") {
        Container(web_app, "Web Application", "React, Vite", "Trang web chính cho sinh viên & Admin. Cung cấp UI đăng ký, bảng dashboard.")
        Container(mobile_app, "Mobile App", "React Native", "Ứng dụng quét QR check-in qua camera, đồng bộ ticket và lưu cache offline vào máy.")
        
        Container(nginx, "API Gateway / Load Balancer", "Nginx", "Reverse proxy tiếp nhận requests từ Web/App, cân bằng tải giữa các node API.")
        
        Container(api, "Backend API Nodes", "Node.js, Express", "Xử lý Session, Verify Payment, cấp S3 Presigned URL, xử lý Create Workshop.")
        Container(worker, "Background Workers", "Node.js", "Consumer chịu trách nhiệm xử lý nạp CSV stream tốc độ cao & push notifications.")
        
        ContainerDb(db, "Primary Database", "PostgreSQL", "Lưu Users, Workshops, Tickets, check-in log. Sử dụng Pessimistic Locking FOR UPDATE khi tính ghế.")
        ContainerDb(cache, "Cache / Rate Limiter", "Redis", "Phân giải TTL Cache (New & Event-Time), thuật toán Rate Limit (Sliding Window), Circuit metrics.")
        ContainerQueue(queue, "Message Broker", "RabbitMQ", "Trung tâm giao tiếp bắn Async Job (Upload CSV job, Notification queue).")
    }

    Rel(student, web_app, "Sử dụng trang", "HTTPS")
    Rel(admin, web_app, "Sử dụng trang", "HTTPS")
    Rel(staff, mobile_app, "Thiết bị cấp phát", "HTTPS")

    Rel(web_app, nginx, "Gọi tính năng", "HTTPS / JSON")
    Rel(mobile_app, nginx, "Call/Đồng bộ", "HTTPS / JSON")

    Rel(nginx, api, "Điều phối Load Balancing", "HTTP")

    Rel(api, db, "R/W (Lock Seat Transaction)", "TCP/IP")
    Rel(api, cache, "Tính TTL / Store Rate Limit", "TCP/IP / RESP")
    Rel(api, queue, "Publish Sync/Notify message", "AMQP")
    
    Rel(worker, queue, "Consume/Subscribe queue", "AMQP")
    Rel(worker, db, "TRUNCATE Staging, Copy Stream, UPSERT Merge", "TCP/IP")
    Rel(worker, aws, "Stream GetObject S3ReadStream", "AWS SDK")

    Rel(api, payos, "Lập link thanh toán, xử lý Webhook", "HTTPS")
    Rel(api, aws, "Lấy URL Upload/Download", "AWS SDK")
```
