1. Vào thư mục api (module Backend) -> npm install
2. Vào thư mục web (module Frontend Web) -> npm install
3. Vào thư mục api (module Backend) -> npm run dev
4. Vào thư mục web (module Frontend Web) -> npm run dev
5.Vào thư mục /source -> chạy docker-compose up -d

Sau đó truy cập localhost rồi code bình thường

Sau khi code xong phải dựa vào code gốc để viết Jest test cho từng phần.
Sau khi test xong hết thì push code lên branch, CI sẽ tự động check để xem có cho merge không
Nếu CI xanh thì leader sẽ merge code 

Thế là xong luồng dev, luồng deploy (CD) thì tính sau....
